What this means in practice
---------------------------

You may read, run, modify, and redistribute this work for research, teaching, personal, and other noncommercial purposes, provided you give attribution to the author and to the companion manuscript relevant to the part you used (see CITATION.cff).

You may not use this work, or anything derived from it, for commercial purposes without a separate written licence. See "Commercial use" below.

How attribution travels
-----------------------

No one can grant rights they do not themselves hold. If someone builds this work into something larger, they must attribute the author; and anyone using *their* result still needs a licence for the part that originated here, so the attribution and noncommercial conditions reach downstream on their own.

Deliberately absent: ShareAlike. It would force any derivative to carry this same licence, which is a compatibility burden on anyone integrating this work into a larger design — and it buys no additional protection, because attribution and the noncommercial term already travel with the material. What a derivative work chooses to call itself is not something this project needs to control.

Commercial use
--------------

Commercial use is not granted by the public licence. That is not a closed door — it is an open one with a doorbell, and the doorbell is answered.

If you want to use any part of this in a product, a funded evaluation, or an industrial research programme, write to sigmansslee@gmail.com. Say which parts interest you and what you intend to build. Terms are negotiable and I am the sole copyright holder, so I can grant them directly — there is no institutional approval chain in the way. Enquiries get a reply.

What a licence cannot do
------------------------

A licence governs copying and adaptation. It cannot compel citation, and it cannot reach through a citation chain: if a third party cites a paper that cited this work, that third party is under no licensing obligation here. Attribution beyond direct reuse is an academic norm, enforced by convention and journal policy rather than by copyright.

A note on the sidebar
---------------------

GitHub identifies a licence by matching the repository's root licence file
against known texts. This file is an explanation of a two-part arrangement
rather than a copy of either licence, so the sidebar will not show a licence
name. That is a display artifact, not an ambiguity: the table above says which
terms apply to which paths, and the full texts are in `LICENSES/`.

A single badge could not describe this repository correctly in any case — it
would have to pick one of the two, and would most likely imply that the code is
under a Creative Commons licence, which it is not.
